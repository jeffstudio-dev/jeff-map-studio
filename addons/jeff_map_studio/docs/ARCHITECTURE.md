# 实现结构

## 数据流

`MapProfile → MapGenerator → MapData → MapRenderer → TileMapLayer`

编辑器和运行时都通过 `JeffMap2D` 使用此流程。数据生成只依赖 GDScript 资源、局部随机数和噪声实例，不访问 SceneTree。图集图片也在独立线程生成，`ImageTexture`、TileSet 和节点仅在主线程创建。

## 模块

- `core/`：配置、地图数组、网格转换、生成器、画笔操作、纹理配方、素材映射。
- `render/`：程序图集和原生 TileMapLayer 的高度分层渲染。
- `runtime/`：异步任务、取消令牌、缓存、原子替换、资源存取和原生场景烘焙。
- `ui/`：可在编辑器或独立演示中使用的工作区，不调用 EditorInterface。
- `editor/`：EditorPlugin 注册、主工作区挂接、场景应用和 EditorUndoRedoManager。
- `examples/`：可直接加载的配置、配方库、已绑定图集库和 PNG。

## 数据约定

地图为稠密矩形数组，索引 `r * width + q`。方形使用 `(x,y)`；六角使用轴向 `(q,r)`，边界是轴向矩形。地形为 PackedInt32Array，-1 表示空；高度、装饰、锁定和手绘标记为 PackedByteArray。

六角邻接始终为六邻接。显示适配层把轴向坐标转换为 Godot stacked offset 坐标；等角六角通过压缩格子投影尺寸显示，不改成菱形 TileSet。坐标测试同时检查逻辑往返和 Godot 原生 `map_to_local()`。

## 渲染与排序

每层高度分别建立顶面、侧面和装饰 TileMapLayer，共享 TileSet。所有层在同一 Y-sort 父节点下，图层位置按高度向上移动，Y-sort origin 抵消高度偏移，以底面位置排序。

内置顶面图集包含所有四边／六边连接组合和两个纹理变体；连续地形内部没有轮廓线，边缘提供材质明暗。侧面只绘制朝向观察者且未被邻格遮住的高度条带。装饰对齐底面锚点。原生 TileMapLayer 按行进行 Y-sort 批处理，避免每格创建 Node2D。

内置形状蒙版向外覆盖一个纹素，并为透明边缘填充邻近 RGB，避免分数缩放时的漏像素和平滑过滤黑边。逻辑坐标与选格多边形保持原始尺寸；实际拼接由 `test_seams.gd` 的图形像素检查验证。

1.1 的 `MapBlockSurface` 为图集与单块预览提供共用的顶面／侧面栅格化。方形等角顶面按平面 UV 投影；侧面按边方向采样材质并增加朝向明暗。素材来源 0/1/2/3 分别为顶面、高度侧面、装饰、底座侧面。`base_side` 位于高度 0 下方，只在邻格为空或越界时绘制；选格也覆盖这段底座。底座厚度不参与地图数组、生成器随机数或连通性计算，该功能本身不改变生成器结果。当前生成器版本因新增装饰分布升级为 1.1.0；旧地图数据仍可读取。

材质细化由 `MapTextureFactory` 绘制带周期环绕的草簇、碎石、砖面磨损、波纹和砂砾；这些局部图形使用单独种子的随机数，不影响地图生成。`MapBlockSurface` 负责侧面的苔藓叶丛、砖层倒角和水／土分层，预览与图集共用外边缘着色。连续同类顶面的内部边缘不描线。材质算法变更后图集缓存前缀更新为 `coastal2`，避免复用旧图集。

外部 TileSet 整体复制，保留 Terrain 与属性层，再追加内置侧面／装饰来源，避免复制单个来源时丢失 Terrain 定义。素材选择固定按 source / atlas / alternative 排序，再用独立的坐标随机流选择权重变体。

## 取消与提交

每个请求分配递增 token。新请求取消旧 worker；worker 定期读取互斥锁保护的取消标记。主线程铺图约每 6ms 检查一次分帧预算，暂存地图在完成前不可见。过期结果不会覆盖当前地图，错误不会提交半张地图。

`_exit_tree()` 取消并回收本节点启动的线程。缓存最多保留两套图集；工作区历史最多 16 份快照。首次创建纹理、引擎刷新 TileMapLayer 或释放旧地图时，单帧仍可能较长；性能报告应区分数据生成时间和包含引擎刷新的实际耗时。

## 扩展

增加生成器时输出 MapData，不直接创建瓦片；新增地形类别需同步调色板、绑定界面和素材校验。新增外部素材规则通过 MapTileRule 表达。添加运行时玩法时使用格子查询接口，不把显示高度当作现成的碰撞或寻路系统。

修改噪声、连接算法、规则顺序或数据格式时更新 `MapData.GENERATOR_VERSION`，并更新确定性和资源回读测试。

双风格标志物由 `MapLandmarkArt` 从两个 `MapLandmarkSource` 原生 Image 资源中读取；工作线程仅处理 Image，主线程创建 ImageTexture。装饰 ID 0–6，对应无、树木、岩石、木箱、蘑菇、棕榈树、灯塔。手绘顶面使用周期笔触与叠色，像素顶面保留离散像素图案；两者均不消耗地形随机流。

`MapSurfaceArt` 从两套原生 Image 资源读取绘制材质，以配方控制配色、细节和重复尺度。`TextureRecipe.illustrated` 对旧资源默认 false，对新的自然材质预设为 true。高度侧面增加五个纵向相位，依地表至当前高度的距离选择，使断面纹理跨层延续；不改变侧面遮挡掩码。
