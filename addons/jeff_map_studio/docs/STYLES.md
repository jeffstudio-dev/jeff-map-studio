# 手绘与像素地块 · 当前本地版

本轮重新绘制两套地块表现和六类标志物，尚未打包。方形、尖顶六角、平顶六角都可使用；切换风格只重新渲染，不修改地图格子、手绘标记、锁定状态或物品位置。

## 两种风格

- **像素风**：地表、侧面和标志物共用一套与屏幕对齐的逻辑像素网格，等角投影不再把像素斜切成菱形。每种材质由配色生成 6 级冷暖色阶（暗部偏蓝紫、亮部偏暖黄），用成片色块、单像素宽的砖缝／岩缝／沙纹线条和 Aseprite 绘制的像素簇（草簇、小花、卵石、波光）组成；暴露的顶面边缘有一像素高光或阴影，草地侧面有下垂草沿与阴影。图案在网格上周期连续，跨格无接缝；两个变体只在格子内部不同。标志物为 Aseprite 绘制的像素精灵，按整数倍放大，像素尺寸与地表一致，并带半透明接触阴影。
- **手绘风**：顶面采用配套绘制的叶簇、风纹、浅水纹；侧面采用带根系的土壤、嵌石与沙岩断面。标志物为独立的手绘图像，使用线性过滤。

旧资源的 `Style.SOFT = 1` 和文件名中的 `soft` 保留以兼容既有配置，现在对应手绘风。`Style.PIXEL = 0` 不变。外部导入图集继续使用其原始图片，不会被自动重绘。

像素风的“像素步长”以 64 px 地块为基准：步长 2 表示一个地块宽 32 个逻辑像素，地块尺寸改为 128 时像素同步放大为 4 px，保持同样的颗粒感。标志物按“地块尺寸 ÷ 32”整数放大，与默认步长 2 完全对齐；地块过小时才缩小。手绘风的渲染与输出没有变化。

装饰密度控制整体出现概率；调密度不改变地形和高度。可用装饰画笔在任意实心格子手工放置，选择“移除装饰”清除物品。锁定格子的物品会在重新生成时保留。每格仍只支持一个装饰 ID。

## 操作

1. 地图页右侧选择“像素风”或“手绘风”。
2. 使用“装饰”工具与物品下拉框在地图上放置。调整“装饰密度”后重新生成，可查看自动分布。
3. 在“纹理与地块”页选择风格和材质预设，再选“单块标志物”，查看三种形状的完整地块。
4. “导出当前地块 PNG”包含预览中选定的物品；“应用纹理到地图”只应用材质，地图物品由装饰画笔或生成器管理。
5. “使用绘制材质”：手绘风控制草地、沙地、水域的绘制纹理；像素风控制是否叠加像素簇与水面波纹，关闭后只保留程序色块。仍可调配色、纹理细节、种子与像素步长；纹理尺度按完整重复次数调整以保持边缘衔接。
6. 可打开 `examples/styles/` 中的六份 `.tres` 地图，对比同一布局的两种风格。该目录另有四种材质 × 三种形状 × 两种风格的 24 张带物品的透明地块 PNG。

## 素材与实现

### 像素风（Aseprite）

像素图在 Aseprite 中制作，源文件位于 `assets/pixel/`，可直接用 Aseprite 打开修改：

| 文件 | 内容 |
|---|---|
| `landmarks.aseprite` | 六个标志物，每帧一个，帧标签为 tree / rock / chest / mushrooms / palm / lighthouse；`contact shadow` 图层 50% 不透明度 |
| `clusters.aseprite` | 地表像素簇，标签 grass_tufts / grass_flowers / sand_pebbles / water_glints / rock_chips；底部中心为锚点 |

`clusters.aseprite` 的前 6 个灰阶色是“色阶键”，运行时替换成当前材质的 0–5 级色阶；其余为固定点缀色（奶白、黄、淡紫、贝壳粉）。新增帧只能使用调色板中的这些颜色，导入时会报出越界颜色。物品使用自身调色板，描边采用相邻材质的深色而非纯黑。

修改后在后台导出并转为运行时资源（Aseprite `-b` 批处理、Godot `--headless`，不打开窗口）：

```sh
python3 tools/export_pixel_art.py --aseprite /path/to/aseprite --godot /path/to/godot
```

脚本导出 `landmarks.png/json`、`clusters.png/json`，再由 `tools/import_pixel_art.gd` 生成 `landmarks.res`、`clusters.res`，供工作线程读取。`tools/aseprite/author_pixel_art.lua` 是首次生成这两个源文件的引导脚本，默认不覆盖已有文件。

地表与侧面图案由 `render/pixel_art.gd` 按配色、种子、网格形状实时生成，因此不是固定图片；它只从 Aseprite 资源中取像素簇。

`assets/surfaces/pixel_source.png`、`assets/landmarks/pixel_source.png` 及对应 `pixel.res` 是上一版 AI 生成的像素素材，运行时已不再引用，保留待确认后再决定是否删除。

### 规范驱动的地形（当前：像素风草地）

像素风草地已改为“Aseprite 概念图 + 外观规范 + 代码绘制”，其余地形暂用内置规则，之后逐个迁移（见 `design/DESIGN.md`）。

| 文件 | 作用 | 怎么改 |
|---|---|---|
| `art/concepts/pixel/grass.aseprite` | 概念图：`reference` 目标样板（只供评审），`palette` 色阶切片 `ramp/*`、点缀色 `accent/*`，`motifs` 图案切片 `motif/<组>/<序号>` | 用 Aseprite 打开直接改；图案用调色板里的**真实颜色**画，导入时自动反查成色阶序号，换主色会跟着变色 |
| `art/concepts/pixel/grass.res` | 导入后的概念数据（色阶、点缀色、图案） | 运行下面的导出命令自动生成，不手改 |
| `art/specs/pixel/grass.tres` | 外观规范 `TerrainArtSpec` | 在 Godot 检查器里改；改后重新生成地图即生效（图集缓存键含规范指纹） |

修改概念图后，在后台导出并导入（Aseprite `-b`、Godot `--headless`，不开窗口）：

```sh
python3 tools/export_concepts.py --aseprite /path/to/aseprite --godot /path/to/godot
```

草地规范的主要设置：

- **四种情绪**：同一张地图里的草地分成常规、花丛（偏亮、成簇小花）、茂密（偏暗、草簇加倍）、苜蓿（最暗、苜蓿叶）。每种情绪的明暗偏移在 `variant_tone_bias`，图案数量倍率在各图案层的 `variant_scales`。
- **按区域成片**：`variant_region_cells` 控制区域大小（单位：格），`variant_order` 让相邻区域按“花丛 → 常规 → 茂密 → 苜蓿”过渡，`variant_mix` 控制区域内的混合程度。改用地图种子计算，不影响地形本身。
- **格内子变体**：四周都是同类地形的格子（地图的绝大多数），每种情绪另有 4 个子变体，避免同一图块整齐重复。
- **无缝**：变体只改变离边缘一个像素步长以外的内部，任意两个变体相邻都不会断（有自动测试）。
- 修改后检查器里点保存即可；把 `version` 加一可以强制所有缓存重建。

图集布局随之调整：顶面图集按“列 = 变体 × 8 + 地形、行 = 邻接掩码”排列，掩码之后的几行是格内子变体（坐标由 `MapAtlasBuilder.top_coords()` 给出）。像素风顶面图集内存约为原来的 2.1–2.4 倍：64 px 地块方形 4.8 MB、六角 14.7 MB；128 px 六角约 58 MB。64 px 地块的烘焙时间约 0.42 秒，在工作线程内完成。手绘风只改了图集布局，渲染结果与改动前逐字节一致。

### 手绘风

地表、断面和标志物使用内置 imagegen 生成。材质图集保存在 `assets/surfaces/painted_source.png`，透明标志物图集保存于 `assets/landmarks/painted_source.png`。提示词、修订说明、来源文件及校验值见 [generation.json](../assets/landmarks/generation.json)。它们不是从用户参考图中裁切的素材，也没有引入第三方图库资源。

`tools/import_landmarks.gd` 在后台将每张 3×2 图集切分为六个 Image，保留 Alpha，统一锚点后保存为 `.res`。运行时预加载原生资源，在独立线程生成装饰图集，主线程创建纹理。预览、实际 TileMapLayer 和场景烘焙共用这些图像。`tools/import_surfaces.gd` 把材质图集切分为六块原生 Image，并处理重复边缘。高度侧面用五个纵向相位连续采样，循环后可能出现材质重复；不为每层重复一条完整的草沿。

## 验证边界

本轮仅使用 `--headless`。`tools/render_style_samples.gd` 从实际 TileMapLayer 的选块、绘制原点和排序锚点，以 CPU 合成六张小地图，覆盖草地、沙地、水域、高低落差和物品。输出位于 `test_output/style_landmarks/`，485 项检查通过。

2026-11-03 草地改为规范驱动后使用 Godot 4.7.2 后台回归，全部通过：核心 481、素材 123、工作区 60、运行时演示 10、地块 87、双风格与标志物 128、外观规范 134（规范自检、颜色只来自色阶、16 个变体两两无缝、区域分布、图集坐标）、干净工程编辑器与保存场景运行、后台性能（512×512 方形／六角）。接缝测试需要图形环境，已明确跳过。手绘风的预览图和示例 PNG 与改动前逐字节一致。

这些导出是实际插件图集的后台合成预览，不是 GPU 截图。分数缩放、最近邻过滤及真实图形后端的接缝和遮挡，仍需本地视觉验收。发布 ZIP 未重新打包。
