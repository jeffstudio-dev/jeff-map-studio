# Jeff Map Studio 1.1

Godot 4.7.2 / GDScript / 无第三方运行时依赖。

## 安装

将 `addons/jeff_map_studio` 复制到项目中，在 **项目设置 → 插件** 启用 **Jeff Map Studio**。首次安装会由 Godot 导入图标和示例纹理。编辑器顶部出现 **Map Studio** 主工作区。

本版在 Godot 4.7.2 标准版上验证；不要求 .NET。运行时核心和渲染器不依赖 EditorPlugin。仅使用烘焙的原生场景时，可以不携带本插件。

## 地图制作

1. **生成**：选择预设；设置种子、尺寸、网格和生成参数；点击生成。默认 128×128，范围 8–512。
2. **显示**：俯视／等角、像素／手绘、六角尖顶／平顶切换会重新渲染并保留格子数据。方形／六角切换需要重新生成。
3. **画笔**：支持地形、擦除、相邻区域填充、升高、降低、树木／石头／木箱／蘑菇群／棕榈树／灯塔，以及锁定／解锁。
4. **保留修改**：重新生成保留尺寸和网格相同的锁定格子，包括空格子、地形、高度、装饰与手绘标记。未锁定的手绘修改会被生成结果覆盖。
5. **撤销**：工作区保留最近 16 份地图状态。快捷键为 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。每次笔划、生成和显示切换分别形成一条记录。
6. **应用**：编辑器中的“应用到当前场景”创建一个 `JeffMap2D`；选择已有 `JeffMap2D` 后应用会更新它。整个应用操作进入 Godot 编辑器撤销历史。

锁定保护重新生成，仍允许手工编辑。地牢／洞穴在生成后保持结构连通；锁定覆盖可能人为断开地图，状态栏会提示这种情况。

### 画布操作

- 滚轮缩放；右键或中键拖动画布。
- “适应画布”或画布获得焦点后按 F 居中地图。
- 左键使用当前工具，半径 0 表示单格。
- 金色标记表示锁定格子；悬停显示坐标、地形、高度和锁定状态。
- 拖动升降画笔时，每个格子在同一次笔划中只升降一次。

### 生成器

| 生成器 | 参数 | 算法 |
|---|---|---|
| 自然地形 | 噪声尺度、层数、海平面、沙滩宽度、山地强度、平滑、装饰密度 | 高度／湿度／温度噪声，海岛衰减，地形阈值 |
| 房间地牢 | 房间数、尺寸范围、走廊宽度、额外连边概率 | 不重叠采样、最小生成树、网格 A* 走廊 |
| 洞穴 | 初始墙比例、迭代次数、最小区域面积、走廊宽度 | 细胞自动机、区域过滤与连通 |

方形房间为矩形，六角房间为轴向六边形。无法放入指定数量房间时会明确报错，保留旧地图；可以缩小房间、减少数量或扩大地图。

相同引擎版本、生成器版本、参数、素材库和种子产生相同结果。地形、装饰和瓦片变体使用独立随机序列。噪声算法或资源规则升级可能改变未来版本的结果，因此需要长期保存的地图应保存 `MapData`，而非仅保存种子。

## 高低地块

高度为 0–16 的整数；等角模式显示方块／六角柱的顶面、可见侧面和悬崖，俯视模式显示顶面。每格只保存一个地表顶面。遮住的侧面不绘制，地块和装饰按底面锚点排序。

1.1 新增 **底座厚度**（0–64 偶数像素）：它向高度 0 的平面下方延伸，适合水柱、厚草块和分层沙土。它不修改格子的整数高度，也不改变连通性。相邻格子之间的底座侧面隐藏，只显示地图边界和空洞处的可见面。底座侧面可以正常选格和绘制。新工作区及预设默认厚度为 16；旧配置缺少该字段时使用 0。俯视显示隐藏底座。

本版高度只影响画面，不生成角色控制器、可行走高度连接或寻路图。生成器内部的 A* 只用于连接地牢结构。运行时可用 `get_cell()` 获取地形和高度自行接入游戏逻辑。预览和烘焙层默认关闭碰撞与导航，导入 TileSet 的原始属性层会保留在资源中。

## 程序纹理

在“纹理与地块”页选择草地、沙土、岩石、水面或石砖；调整种子、分辨率、配色、颗粒、尺度和像素步长。中央可切换 **立体地块** 与 **3×3 平铺**。

立体预览支持点击下方三张卡片，检查等角方形、尖顶六角柱和平顶六角柱。左侧增加苔藓草块、青玉砖块、浅海水柱、分层沙土四套配色预设。继续向下滚动可调整底座厚度、侧面纹理、侧面细节强度及两种侧面颜色。顶面和侧面分别保留自己的材质参数；改变侧面配方后点击“应用纹理到地图”。

“导出当前地块 PNG”输出当前选中形状的透明图片，宽度根据纹理分辨率取 16–256 的偶数，四周保留透明边距。导出的整块图片包含顶面和侧面，适合美术检查或作为独立图块使用；地图自动隐藏侧面时使用分开的顶面／侧面图集。`examples/blocks` 附带四套配方及三种形状的 12 张透明示例。

- 保存配方：`.tres`，类型为 `TextureRecipe`。
- 导出图片：无缝 PNG。
- 应用到地形：更新内置地块的对应材质并重新渲染；地图的像素／手绘显示选项决定最终风格。
- 外部图集使用自身图片。需要使用程序纹理时，先保存自己的素材库，再恢复内置素材库。

`examples/textures` 附带两种风格的 10 张纹理和对应配方。`examples/libraries` 提供自然／地牢配方库和四套已绑定的方形／六角图集库；`examples/profiles` 提供相应配置。

## 导入 PNG 与 TileSet

### PNG 图集

先设置图集格宽／格高、边距和间隔，再导入 PNG。点击预览选择图集格子，或输入 X、Y。每个绑定指定：

- **地形**：水域、沙地、草地、泥地、岩石、雪地、墙体、地板。
- **用途**：顶面、侧面、装饰。
- **来源／坐标／替代 ID**：对应 Godot TileSet 的瓦片标识。
- **边掩码／角掩码**：`-1` 为任意；精确匹配优先于通用绑定。
- **权重**：同等匹配度下的确定性随机选择权重。
- **装饰类型**：任意、树木、石头、木箱、蘑菇群、棕榈树、灯塔，仅用于装饰规则。

可设置选中瓦片的绘制原点与 Y 排序锚点；正的绘制原点让图片向左／向上偏移，地块底面应对准同一格子中心。设置后点击“应用素材库到地图”查看结果。

所有使用中的地形都必须有顶面绑定。缺少地形或邻接组合时，错误会给出首个格子和掩码，地图不会被半成品覆盖。侧面和装饰未绑定时使用内置侧面／装饰。

### Godot TileSet

可直接载入 `.tres`／`.res` TileSet，保留原始资源属性与替代瓦片。设置匹配的地图格子尺寸、网格和投影，再绑定地形。“读取 TileSet Terrain 规则”把有效的原生边／角信息和权重转成规则；原生 Terrain 0–7 默认对应工具的八种地形，必须核对语义，不匹配时删除相应规则并重新绑定。

每个素材库绑定到一种网格、投影和六角朝向。任意图片不会自动识别成完整地形集；内置模板才提供完整边缘组合。

### 掩码顺序

位为 `1 << 方向序号`。顶面位表示相邻格子的地形相同，且在等角模式中高度相同；侧面位表示该方向需要绘制可见面。

| 网格 | 方向序号 0 → |
|---|---|
| 方形逻辑坐标 | `(1,0), (0,1), (-1,0), (0,-1)` |
| 六角轴向坐标 | `(1,0), (0,1), (-1,1), (-1,0), (0,-1), (1,-1)` |
| 方形角 | `(1,1), (-1,1), (-1,-1), (1,-1)` |

方形边掩码范围 0–15，六角为 0–63，方形角为 0–15。全连接方形顶面为 15，六角为 63。内置模板为每种地形提供完整边组合与两个纹理变体；过渡表现为材质边缘，不包含自动识别美术或任意材质之间的语义混合。

## 保存与导出

- **保存配置**：`MapProfile.tres`，保存生成参数，不含手绘地图。
- **保存地图**：`MapData.tres`，包含地形、高度、装饰、手绘标记、锁定状态和当前素材库。
- **导出场景**：`.tscn` + 同名 `_assets` 目录。场景只包含原生 `Node2D`／`TileMapLayer`，素材使用压缩的 `tileset.res`，另附 PNG 图集。

移动烘焙地图时必须同时移动 `.tscn` 和整个 `_assets` 目录。工作区“打开”可加载配置或地图。工程外的文件也可保存，但要放回游戏项目再作为打包资源使用。

## 运行时 API

```gdscript
extends Node2D

@onready var map: JeffMap2D = $JeffMap2D

func _ready() -> void:
    map.generation_completed.connect(_map_ready)
    map.generation_failed.connect(func(message: String): push_error(message))
    map.generation_progress.connect(func(value: float, stage: String):
        print(stage, " ", int(value * 100), "%"))

    var settings := MapProfile.new()
    settings.seed_value = 12345
    settings.grid = MapProfile.Grid.HEX
    settings.projection = MapProfile.ProjectionMode.ISOMETRIC
    settings.width = 128
    settings.height = 128
    settings.base_thickness = 16
    map.generate(settings)

func _map_ready(data: MapData) -> void:
    print(data.content_hash())
    print(map.get_cell(Vector2i(5, 5)))
    print(map.cell_to_local(Vector2i(5, 5)))
    map.save_map("user://my_map.tres")
```

| 接口 | 行为 |
|---|---|
| `generate(profile)` | 后台生成并分批渲染；兼容尺寸／网格时保留当前锁定格子 |
| `apply_data(data)` | 校验并渲染已有地图，不重新随机生成 |
| `cancel_generation()` | 取消当前请求并保留上一份已提交地图 |
| `generation_progress(value, stage)` | 0–1 的当前阶段进度，阶段切换时可能重新计量 |
| `generation_completed(data)` | 数据和可见地图已一起提交 |
| `generation_failed(message)` | 校验、素材映射或生成失败，旧地图保持可见 |
| `generation_cancelled` | 当前请求已取消 |
| `get_cell(cell)` | 返回 terrain、height、decoration、locked、manual；越界为空字典 |
| `cell_to_local(cell, include_height)` | 格子到地图局部坐标 |
| `local_to_cell(point)` | 基于高度和遮挡选格；无命中返回 `(-1,-1)` |
| `save_map(path)` / `bake_scene(path)` | 保存资源／导出原生场景，返回 Godot Error |

`MapGenerator.generate(profile, previous, job)` 是同步的纯数据接口，可用于服务端或自己的任务系统。`JeffMap2D` 封装线程、取消、图集缓存和主线程更新。运行时写文件请使用 `user://`。

## 版本范围

首版提供有限地图、固定投影和单格单顶面；不包含无限世界流式加载、节点图编排、真正 3D 地形或角色寻路。地图结果中包含生成器版本；本版没有旧格式迁移需求。

参考项目与素材说明见 [REFERENCES.md](docs/REFERENCES.md)，实现结构见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)。
